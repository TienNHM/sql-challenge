# 30 Days SQL Challenge

Lộ trình học SQL trong 30 ngày, mỗi ngày một bài, từ `SELECT` cơ bản đến index, transaction, window function, tối ưu truy vấn và bảo mật database. Có ba bài ôn tập giữa chặng và một bài tổng kết.

👉 Bắt đầu tại [Lộ trình học SQL](lessons/00-30-day-sql-learning-roadmap.md).

## Cách học

- Học theo thứ tự, mỗi ngày một bài. Cuối mỗi bài có liên kết sang bài trước/sau.
- Gõ lại và chạy các câu lệnh ví dụ trên MySQL, PostgreSQL hoặc SQLite (hướng dẫn cài đặt ở [Ngày 1](lessons/01-intro-to-sql-and-dbms.md)).
- Làm hết bài tập trong các bài ôn tập (ngày 7, 14, 21) trước khi sang chặng tiếp theo.
